# Promptenhorn

*Matterhorn, сложенный из промптов.* Внутри игры мир называется Claude Alps.

Каждый чат с Claude Code становится строителем в Minecraft. Пока Claude работает, строитель (Стив, Алекс, Кай…) возводит дом. Из домов вырастает швейцарский городок: сначала деревня из шале, потом старый город с аркадами, церковью и отелем, затем современные кварталы.

Токены не тратятся: hooks — обычные локальные команды, они ничего не выводят в чат, ничего не решают за Claude и запускаются в фоне (`async`), так что Claude их не ждёт.

## Как это устроено

```
Claude Code ──hook──▶ hooks/alps-hook.mjs ──HTTP──▶ bridge/bridge.mjs ──RCON──▶ Minecraft (Paper 1.21.11)
                                                        │
                                                        └── http://127.0.0.1:7777/  страница настроек
```

| Событие Claude Code | Что происходит в мире |
|---|---|
| Новый чат | Появляется строитель |
| Твоё сообщение | Строитель получает имя (первые слова запроса) и получает участок |
| Claude правит файлы, запускает команды | Стройка идёт (~3 блока/с) плюс бонус за каждое действие |
| Claude закончил ответ | Строитель ждёт у дома; через 30 минут ложится спать |
| Дом достроен | Фейерверк, в дом заселяется житель, строитель идёт на следующий участок |
| Чат закрыт | Строитель уходит; недостроенный дом достроит следующий чат |

- Один проект (папка) = один квартал. Город ставится в альпийской долине среди гор.
- Справа сайдбар со всеми активными чатами и процентом готовности.
- При входе в игру в чате появляется список кварталов (клик телепортирует) и ссылка на настройки.

## Приватность

Хук сам сводит событие к мелким признакам и отправляет в мост только их: имя инструмента, тип уведомления, «это был тест, он упал», «это был коммит». Команды, содержимое файлов, вывод инструментов и ответы Claude из хука не выходят. Исключение — первые слова первого сообщения: они становятся именем строителя. Текст задачи в книгу хроники попадает только при включённой опции «Текст задачи в хронике» (во всех пресетах выключена).

## Запуск

Нужны Java 21+ и Node.js 18+.

1. Один раз установить hooks:
   ```
   node install-hooks.mjs
   ```
   Скрипт добавит hooks в `~/.claude/settings.json` и сделает бэкап рядом. Чужие hooks не трогаются, повторный запуск безопасен. Подхватят только новые чаты.
2. Запустить сервер и мост: двойной клик по `start.cmd` (откроются два свёрнутых окна).
3. В TLauncher выбрать версию **1.21.11** → «Сетевая игра» → сервер `localhost`.
4. Работать с Claude как обычно и смотреть, как растёт город. Летать в creative или `/gamemode spectator`.

Посмотреть без настоящих чатов: при запущенном мосте выполнить `node demo.mjs 3`.

## Настройки: пресеты и функции

Открой **http://127.0.0.1:7777/** (ссылка «[настройки]» есть и в игровом чате при входе). Изменения применяются сразу, без перезапуска, и сохраняются в `config.json` (`preset` + `features`).

| Пресет | Что включено |
|---|---|
| Минимум | Строители и дома, как в первой версии |
| Базовый (по умолчанию) | Проверенные функции, которые не шумят |
| Максимум | Все проверенные функции |

Поверх пресета любую функцию можно включить или выключить переключателем. Функции с меткой «экспериментально» написаны, но ещё не проверены в мире целиком: они не входят ни в один пресет и включаются только вручную. Состояние каждой функции — в `docs/roadmap.md`.

То же из терминала:

```
node configure.mjs                 # пресет и все функции
node configure.mjs basic           # выбрать пресет (minimal | basic | max)
node configure.mjs tests on        # включить одну функцию поверх пресета
node configure.mjs tests reset     # вернуть как в пресете
```

Работающий мост подхватывает изменения `config.json` в течение пары секунд.

### Функции

| Группа | Функции |
|---|---|
| Работа Claude | Строитель зовёт тебя (ждёт разрешения или ответа: «!», колокол, красная полоса), жёлтая полоса «ждёт задачу», тесты (искры, флажок, тучка), коммит = колокол, push = автобус ПостАвто, PR = флаг кантона, веб-поиск = почтовый аллей, компакция = перекур, лимит API = гроза в горах, plan mode = архитектор |
| Строители | Статус под именем, инструмент в руке, подмастерья-субагенты |
| Город | Реальные сутки, свет в окнах, дым из трубы, экономика чатов, **ремонт вместо сноса**, жители по профессии, строительные леса, бой часов |
| Прогресс | Достижения, хроника дома, статус посёлка (Weiler → Stadt), франки за токены, Маттерхорн-прогрессбар |
| Информация | Ратуша (окно со всеми строителями), locator bar, «пока тебя не было» |
| Пасхалки | Альпхорн, мелочи (TNT на rm -rf, каска по модели), SBB-часы, 1 августа и Рождество |
| Приватность | Текст задачи в хронике (только вручную) |

### Параметры

На той же странице: сколько действий нужно чату до своего дома и до следующих этапов (экономика чатов), скорость стройки и скорость ремонта. Остальные значения можно задать в `config.json`:

```json
{
  "preset": "basic",
  "features": { "status": true },
  "blocksPerSecond": 3,
  "toolBurst": { "Edit": 10, "Write": 12, "Bash": 5, "default": 3 },
  "idleAfterMinutes": 10,
  "sleepAfterMinutes": 30,
  "retireAfterHours": 72,
  "renovateBlocksPerSecond": 2,
  "maxVillagersPerDistrict": 12,
  "villagerAI": false,
  "scratchDistrictName": "Alpweide"
}
```

Чаты без папки проекта строят общий квартал «Alpweide». Жители по умолчанию стоят на месте (`villagerAI: false`) и их не больше 12 на квартал: сотня бродящих жителей заметно нагружает сервер.

## Ремонт вместо сноса

Когда меняются генераторы зданий, город не строится заново. Мост помнит, какой версией построен каждый участок (архив версий в `bridge/archive/`), и чинит дома по разнице: снимает то, чего больше нет, ставит новое, а совпадающие блоки не трогает.

- Недостроенный дом достраивается уже по новому чертежу.
- Готовые дома, площади кварталов и главную площадь ремонтирует бригада: 2 блока/с, пока работает хоть один чат, плюс бодрствующий свободный строитель квартала приходит помочь. В сайдбаре строка «Ремонт: Шале 40%», по окончании квартала — сообщение в чат.
- Фонари, швы между участками и мостовая версионируются отдельно и обновляются так же.

Подробности для авторов генераторов: `docs/generator-contract.md`.

## Достижения и ратуша

Для достижений и кнопки «Ратуша» в меню паузы мост сам ставит датапак `datapack/promptenhorn` в `server/world/datapacks/` и перезагружает датапаки. Кнопка в меню паузы появится после следующего перезапуска сервера (диалоги загружаются только при старте), ссылка «[Ратуша]» в чате работает сразу.

## Остановка и удаление

- Остановить: в окне сервера ввести `stop`, окно моста закрыть.
- Если мост не запущен, hook видит устаревший heartbeat-файл и выходит сразу.
- Удалить hooks: `node install-hooks.mjs --uninstall`.
