# Promptenhorn

*Matterhorn, сложенный из промптов.* Внутри игры мир называется Claude Alps.

Каждый чат с Claude Code становится строителем в Minecraft. Пока Claude работает, строитель (Стив, Алекс, Кай…) возводит дом. Из домов вырастает швейцарский городок: сначала деревня из шале, потом старый город с аркадами, церковью и отелем, затем современные кварталы.

Токены не тратятся: hooks — обычные локальные команды, они ничего не выводят в чат.

## Как это устроено

```
Claude Code ──hook──▶ hooks/alps-hook.mjs ──HTTP──▶ bridge/bridge.mjs ──RCON──▶ Minecraft (Paper 1.21.11)
```

| Событие Claude Code | Что происходит в мире |
|---|---|
| Новый чат | Появляется строитель и получает участок |
| Твоё сообщение | Строитель получает имя (первые слова запроса) и начинает работать |
| Claude правит файлы, запускает команды | Стройка идёт (~3 блока/с) плюс бонус за каждое действие |
| Claude закончил ответ | Строитель ждёт у дома; через 30 минут ложится спать |
| Дом достроен | Фейерверк, в дом заселяется житель, строитель идёт на следующий участок |
| Чат закрыт | Строитель уходит; недостроенный дом достроит следующий чат |

- Один проект (папка) = один посёлок. Посёлки ставятся на альпийских лугах (биом meadow) среди гор.
- Справа сайдбар со всеми активными чатами и процентом готовности.
- Когда заходишь в игру, в чате появляется список посёлков: клик по названию телепортирует.

## Запуск

Нужны Java 21+ и Node.js 18+ (оба уже установлены).

1. Один раз установить hooks:
   ```
   node install-hooks.mjs
   ```
   Скрипт добавит hooks в `~/.claude/settings.json` и сделает бэкап рядом. Твои существующие hooks не трогаются. Подхватят только новые чаты.
2. Запустить сервер и мост: двойной клик по `start.cmd` (откроются два свёрнутых окна).
3. В TLauncher выбрать версию **1.21.11** → «Сетевая игра» → добавить сервер с адресом `localhost`.
4. Работать с Claude как обычно и смотреть, как растёт город. Летать в creative или включить `/gamemode spectator`.

Посмотреть без настоящих чатов: при запущенном мосте выполнить `node demo.mjs 3`. Три фейковых чата 3 минуты строят посёлок «Demodorf».

## Остановка и удаление

- Остановить: в окне сервера ввести `stop`, окно моста закрыть.
- Если мост не запущен, hook видит устаревший heartbeat-файл и выходит сразу (~0.1 с на вызов).
- Удалить hooks: `node install-hooks.mjs --uninstall`.

## Настройки

Создай `config.json` рядом с этим файлом, чтобы переопределить значения по умолчанию:

```json
{
  "blocksPerSecond": 3,
  "toolBurst": { "Edit": 10, "Write": 12, "Bash": 5, "default": 3 },
  "idleAfterMinutes": 10,
  "sleepAfterMinutes": 30,
  "retireAfterHours": 72,
  "scratchSettlementName": "Alpweide"
}
```

Чаты без папки проекта строят общий посёлок «Alpweide».

## Файлы

| Путь | Что это |
|---|---|
| `bridge/bridge.mjs` | Демон: принимает события, ведёт сессии, планирует участки, ставит блоки |
| `bridge/buildings.mjs` | Генераторы зданий: шале, дом старого города, церковь, современный дом, гранд-отель, площадь с фонтаном |
| `bridge/blueprint.mjs` | Чертёж: рисование, поворот блоков, порядок стройки |
| `bridge/rcon.mjs` | RCON-клиент без зависимостей |
| `hooks/alps-hook.mjs` | Hook для Claude Code |
| `install-hooks.mjs` | Установка и удаление hooks |
| `server/` | Paper 1.21.11: только localhost, offline-mode, peaceful, creative |
| `state.json` | Состояние города (появится после первого запуска) |

Начать город заново: остановить всё, удалить `server/world*` и `state.json`.
