# Localization

English is the default language of the product and the repository. Supported languages: English, Русский, Español, Deutsch, Français, Italiano, Português, 中文, 日本語.

## Rules for code

- Every user-visible string goes through `t()` from `bridge/i18n.mjs`: in-game chat (`tellraw`), sidebar and nametags, dialogs, books and signs, settings and map pages, CLI output of `configure.mjs`.
- Keys are flat and namespaced by module: `hall.title`, `callout.waiting`, `settings.preset.max`. Placeholders use `{name}`: `t('hall.title', { city })`.
- Plurals: pass `count` and define `key.one` / `key.other` (plus `few` / `many` where the language needs them, e.g. Russian). `Intl.PluralRules` picks the form.
- `locales/en.json` is the source of truth: add every new key there first, with natural English. Add the Russian translation to `locales/ru.json` at the same time. The other languages are filled by the localization pass; missing keys fall back to English.
- Don't localize: log lines (`log(...)`), code comments, identifiers, block ids, Minecraft commands. Swiss shop signs on buildings (e.g. `BAECKEREI`) stay Swiss German on purpose.
- The language is a setting (`language`, default `en`) and switches live; the bridge calls `setLanguage()` on start and on every settings reload.

## Rules for docs

- `README.md` and everything in `docs/` are written in English. Translations of the README live next to it as `README.<lang>.md` (e.g. `README.ru.md`) and are linked from the top of `README.md`.
