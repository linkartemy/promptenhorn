# life → bots

1. **Chatter API** (`bridge/features/chatter.mjs`, feature `chatter`, setting `chatterFrequency`):
   - `say(session, key, params?, { priority })` — returns `true` when the line was said. Keys are `chatter.<key>.<n>` in the locales (`wait.permission`, `wait.question`, `tests.fail`, `tests.failAgain`, `tests.green`, `commit`, `push`, `pr`, `apprentice`, `compact`, `limit`, `start.house`, `start.public`, `finish.house`, `finish.stage`, `finish.public`, `renovate`, `feierabend`, `greet`, `morning`, `evening`, `rain`, `banter`). Priority 1 small talk, 2 work news, 3 urgent (also speaks in quiet hours).
   - `registerSpeaker((session, text, line) => boolean)` — register once when the bot backend starts: return `true` when the session's body is a bot and you sent `text` through the bot's own chat (`bot.chat(text)`); otherwise the bridge sends `<Name> text` with `tellraw`. The limiter (global gap, per-builder and per-kind cooldowns, no repeats) is shared, so bots and mannequins never flood the chat together.
   - The feature already reacts to hook events, finishes, renovation help (`pose === 'renovating'`), Feierabend and builders meeting. Your bots' own lines ("Off to build the Old-town house!", "Calling it a day") could go through `say()` too, so they count against the same limit.
2. **ctx.moveTo(session, site)** is now on the feature context (wraps `moveTo` in `bridge.mjs`). The builders' day feature (`builderLife`, mannequin bodies only: `rt(s).body !== 'bot'`) uses it to send a sleeping builder home to its own bed and to the district café after work (17–20 h). It sets `session.pose` to `idle-sleeping` (in bed, with `sleeping_pos`) or `feierabend` (so the renovation helper does not pick it), and releases a job that is not the chat's own house while the chat sleeps (`site.rec.sessionId = null`, `session.job = null`). Please keep these semantics if you change `moveTo` or the idle branch of `work()`.
3. **bedSpot**: your `bedSpot(s)` takes the first bed of the build list; the generator `bed` markers (`data.owner: 'family' | 'guest'`) say which beds belong to the family. `bridge/features/markers.mjs` → `markersOf(ctx, plot)` gives them in world coordinates if you want to use the same bed as the mannequin.
4. **Small change in `work()`** (economy): when an active chat has nothing to build (the town is complete for now — the slope forest is now capped), `work()` emits `onWork` for the site where its builder stands, so the status line, chimney and lights still follow the chat. `chooseJob()` backs off for 20 s after an empty answer.
5. Smooth motion (`smoothBuilders`): a mannequin riding its vehicle renders sitting. `builderLife` dismounts it (`ride … dismount`) before putting it into a bed or onto a café seat; your `glide()` re-mounts on the next move.
