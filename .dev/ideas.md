# Promptenhorn: идеи для «прикольчиков»

Обозначения: **S/M/L** = трудоёмкость. Сигнал = hook-событие и поле. Всё работает на ванильном 1.21.11 через RCON (и кое-где датапак), клиентские моды не нужны.

## Какие сигналы на самом деле есть (по докам hooks, 10.2026)

- `PostToolUse`: `tool_name`, `tool_input`, `tool_response`, `duration_ms`. Для Bash `tool_response` = `{stdout, stderr, interrupted}`, **exit-кода в нём нет**.
- `PostToolUseFailure`: `error`. Для Bash ошибка начинается с `Exit code N`. Ещё есть `is_interrupt`. Так ловятся упавшие тесты и сборки.
- `PermissionRequest` (сразу, `tool_name`) и `Notification` (`notification_type`: `permission_prompt`, `idle_prompt`, `elicitation_dialog`, `agent_needs_input`…). Так понятно, что строитель ждёт тебя.
- `SubagentStart`/`SubagentStop`: `agent_id`, `agent_type` (Explore/Plan/…). `TaskCreated`/`TaskCompleted`: `task_subject`.
- `StopFailure`: `error` (`rate_limit`, `overloaded`, …). `PreCompact`: `trigger` (manual/auto). `SessionStart.source` бывает `compact` и `fork`. `CwdChanged`. `PostModelSwitch.to_model`. Во всех событиях есть `permission_mode` (plan/auto/bypass…).
- git commit/push и `gh pr create` отдельными событиями не приходят. Их достаём регэкспом по `tool_input.command` у Bash, а успех проверяем по паре PostToolUse/PostToolUseFailure.
- Токены лежат в `transcript_path`, поле `message.usage` в строках assistant. Читать на `Stop` инкрементально по offset.
- Хук должен **сам** сводить payload к мелким признакам (`kind:"test"`, `exit:1`, `ext:".ts"`, `agent_type`) и не пересылать сырые команды. Тогда не утекает приватное и тело запроса остаётся маленьким.

## Идеи

### A. Реакция на работу
1. **«Строитель зовёт тебя»**. Над головой красный «!», строитель приседает и встаёт (чередует pose), один удар колокола, красный bossbar «Ждёт разрешения: fix tests [tp]». Сигнал: PermissionRequest, Notification(permission_prompt / elicitation_dialog). Снимается следующим Post*/Stop/UserPromptSubmit. **S**. Риск: колокол только один раз, без повторов.
2. **Тесты зелёные/красные**. Если тесты прошли: восходящий `block.note_block.chime` и зелёные искры. Если упали: дымок, `entity.villager.no`, флажок на лесах становится красным, а 3 падения подряд дают маленькую тучку над домом (частицы `falling_water`). Сигнал: Bash с `test|pytest|vitest|jest|cargo test` плюс Post/PostToolUseFailure. **S**.
3. **Коммит = колокол**. Колокол церкви квартала (`block.bell.use` в координатах колокольни), над домом всплывает text_display «+1 commit» и тает за 2 с через интерполяцию. Сигнал: `git commit` и успех. **S**.
4. **Push = ПостАвто**. Жёлтый «автобус» из block_display едет от дома до главной площади (`teleport_duration`, анимацию рисует клиент). Сигнал: `git push`. **M**.
5. **PR = флаг кантона**. На флагштоке площади квартала поднимается новый баннер. Сигнал: `gh pr create`. **S**.
6. **Субагенты = подмастерья**. Рядом появляется маленький манекен (`attribute minecraft:scale base set 0.6`) с другим скином. У Explore в руке подзорная труба, у Plan карта. На SubagentStop он исчезает с poof и даёт бонус к стройке. Сигнал: SubagentStart/Stop, `agent_id`. **M**. Риск: не больше 4 на чат.
7. **Предмет в руке = текущая работа**. Read/Grep дают книгу, Edit кисть/топор, Bash кирку, Web компас, Agent колокольчик. Менять только когда меняется категория инструмента. Сигнал: `tool_name`. **S**.
8. **Веб-поиск = почтовый аллей**. Allay с NoAI вылетает из окна и через 4 с возвращается (tp с интерполяцией, потом kill). Сигнал: WebSearch/WebFetch. **S**. Риск: троттлинг, не чаще 1 раза в 10 с.
9. **Компакция = перекур**. Строитель 3 с сидит (crouching), в руке кружка (`suspicious_stew`), в actionbar «чат сжал память». Сигнал: PreCompact. **S**.
10. **Rate limit = гроза в горах**. Над кварталом `weather thunder` на 60 с, молнии бьют только по дальним вершинам. Сигнал: StopFailure(rate_limit/overloaded). **S**. Риск: молния рядом с жителем превращает его в ведьму, поэтому только по горам.
11. **Plan mode = архитектор**. Строитель с картой. Контур будущего дома мерцает частицами `end_rod` по углам и уровню крыши, а стройка начинается после выхода из plan. Сигнал: `permission_mode=="plan"`. **M**.

### B. Жизнь и атмосфера
12. **Свет в окнах = чат жив**. В доме активного чата горят `waxed_copper_bulb[lit=true]` (держат состояние без редстоуна) или блоки `light`, у спящего гаснут. Ночью сверху сразу видно, кто работает. **M**: в генераторах нужны «слоты света».
13. **Дым из трубы** у активных: `campfire[signal_fire=true]` под трубой, при простое `lit=false`. Частицы рисует клиент, серверу это почти ничего не стоит. **S**.
14. **Реальные сутки**. `gamerule advance_time false` и раз в минуту `time set` по локальным часам. Ночью город спит вместе с тобой. **S**.
15. **Цитглогге бьёт часы**. Каждый реальный час N ударов колокола и маленький парад белых медвежат (`polar_bear`, NoAI, scale 0.5) вокруг башни. Ночью без звука. **S/M**.
16. **Жители по профессии дома**. Ферма даёт farmer, коров и коз с «колокольчиками» (редкий `note_block.bell` рядом). Церковь даёт cleric, кафе butcher, отель librarian. Всем NoAI. **S**.
17. **Строительные леса** (scaffolding) по краю участка на время стройки, на финише снимаются вместе с фейерверком. **M**. Риск: не ставить там, где идёт стройка по чертежу.

### C. Прогресс и мета
18. **Ачивки-тосты** из датапака: advancement с триггером `minecraft:impossible`, выдаётся `advancement grant @a only promptenhorn:<id>`. Примеры: «Первый камень», «Ночная смена» (работа после 2:00), «Зелёный свет» (тесты прошли после 3 падений), «Улей» (5 субагентов сразу), «Kantonsrat» (10 кварталов). **S/M**.
19. **Статус посёлка** Weiler → Dorf → Städtli → Stadt по числу домов: title/subtitle, новая табличка, на площади фонтан или статуя. **M**.
20. **Франки за токены**. Из транскрипта суммируется только `usage`, над площадью «Kasse: CHF 12 480». **M**. Риск: читать только новые байты, контент не парсить.
21. **Маттерхорн-прогрессбар**. На ближайшей вершине каждые 10 домов города прибавляется кольцо фонарей или крест, видно из любой точки. **M**.
22. **Хроника дома**. На кафедре у двери written_book: «Построил “fix tests”, 25.10.2026, 312 действий, 4 коммита, 2 подмастерья, 38 мин». **S/M**. Приватность: первый промпт вписывать в книгу только по опции.

### D. Информация
23. **Статус под ником**. У манекена есть `description` (сейчас скрыт через `hide_description`), там можно писать «✎ Edit · 64%», «⌛ ждёт тебя», «☾ спит 2 ч». **S**. Самый дешёвый способ сделать связь работы и мира читаемой.
24. **Ратуша-диалог** (`/dialog show`, 1.21.6+): кнопки-телепорты ко всем строителям, наверху те, кто ждёт разрешения. Открывается кликом в tellraw. **M**.
25. **Locator bar**: манекенам выдать `waypoint_transmit_range`, ждущим поставить `waypoint modify … color red`. **S**. Нужно проверить, виден ли бар в creative и spectator.
26. **«Пока тебя не было»** при входе: 3 дома, 7 коммитов, 1 чат ждёт, плюс ссылки [tp]. **S**: расширить `pollPlayers`.

### E. Швейцария и пасхалки
27. **Альпхорн на финише**: `item.goat_horn.sound.0` с низким pitch раскатывается по долине. **S**.
28. **1 августа**: костры на вершинах, флаги на всех домах, фейерверк в 21:00. 25 декабря снег (`weather rain` и снежный биом гор). **S**.
29. **SBB-часы** на башне: стрелка из item_display крутится через интерполяцию и замирает на 58-й секунде на 1,5 с (stop-to-go). **M**.
30. **Мелочи**: если в Bash `rm -rf`, строитель секунду держит TNT (без взрыва). Модель меняет каску: Opus золотой шлем, Haiku кожаная шапка (`SessionStart.model`/`PostModelSwitch`). На Ctrl+C (`is_interrupt`) строитель роняет инструмент. **S**.

## Топ-7: наброски реализации

**1. Статус под ником + предмет в руке (23+7).** В `onEvent` писать в `s.status = {icon, text}` и `s.toolCat`. В `work()` при смене делать `data merge entity @e[tag=…,limit=1] {hide_description:0b,description:{text:"✎ Edit · 64%",color:"gray"}}` и `item replace … weapon.mainhand`. Сравнивать по ключу, как `scoreKey`, иначе пойдут десятки RCON-команд в секунду. Процент обновлять не чаще шага в 5%.

**2. «Строитель зовёт тебя» (1).** В `install-hooks` добавить `PermissionRequest`, `Notification` и `PostToolUseFailure`. Хук ничего не печатает, поэтому решение о разрешении не меняется. Состояние `s.waiting = since`, сбрасывается на Post*/Stop/UserPromptSubmit. Команды: `bossbar add alps:wait_<id>`, `bossbar set … players @a`, color red, `name` с именем чата; один `playsound block.bell.use`; в tick чередовать pose crouching/standing раз в 1 с. Если ожидание висит больше 2 мин, мигание выключать, bossbar оставлять. Подвох: Notification(idle_prompt) приходит и в обычном простое, его показывать жёлтым, а не красным.

**3. Тесты и коммиты (2+3).** Классификацию делать в хуке: `kind` по регэкспу команды (`test|commit|push|pr`), `exit` из первой строки `error`. В бридж уходит только `{kind, ok}`. Эффекты ставить в очередь `effects[]` с лимитом 3 команды за tick, чтобы не тормозить `setblock`. Колокол ищем по координатам церкви квартала: при генерации запомнить в `plot.bell`. Если церкви ещё нет, звенит колокол на главной площади.

**4. Подмастерья (6).** Map `agent_id → entity tag`. Summon mannequin рядом со строителем, `attribute … minecraft:scale base set 0.6`, скин по хэшу `agent_id`. Раз в ~2 с tp к случайному блоку из следующих 20 блоков `list`. На SubagentStop убирать с poof, а `subagentBurst` начислять уже как сейчас. Подвохи: если SubagentStop потерялся, убирать по таймауту 15 мин; у сессии не больше 4 подмастерьев; UUID стабильный, как в `builderUuid`.

**5. Ночной город: время, свет, дым (14+12+13).** В `setupWorld` поставить `gamerule advance_time false`, раз в 60 с `time set <ticks из Date>`. При переходе active↔idle делать один `setblock` на каждый «слот света» и трубу дома (слоты отдаёт blueprint через `bp.mark('light', x,y,z)`). Нужен `forceload` участка, иначе блоки не встанут: использовать уже готовый `holdPlot`. Подвох: менять `buildings.mjs` надо вместе с владельцами генераторов, а хэш чертежа сменится, и это вызовет `restartPlot`. Метки лучше хранить вне `toBuildList`.

**6. Ачивки (18).** Датапак `server/world/datapacks/promptenhorn/` с ~10 JSON-файлами (`criteria: {x:{trigger:"minecraft:impossible"}}`, `display.icon`, `frame:"goal"`). Бридж проверяет условия в `onEvent`/`finishPlot` и вызывает `advancement grant @a only promptenhorn:night_shift`. Подвох: grant выдаётся только онлайн-игрокам, поэтому офлайн-выдачи копить в `state.pendingAdvancements` и раздавать в `pollPlayers`. В `state` хранить, что уже выдано.

**7. Хроника дома (22).** В `finishPlot` поставить `lectern[has_book=true]` у двери и через `data merge block … {Book:{id:"written_book",components:{"minecraft:written_book_content":{title:"…",author:"Claude",pages:[…]}}}}` записать статистику сессии (`tools`, `commits`, `subagents`, `blocks`, время). Счётчики копить в `s.stats` в `onEvent`. Подвох: текст пропускать через `cleanText`; промпт в книгу только при `config.chronicleWithPrompt`.

**Общие подводные камни**
- **Объём хуков.** PostToolUse при 5 чатах даёт до ~5 запусков node в секунду, на Windows это ~50 мс CPU каждый. PreToolUse **не** подключать. Для Post* и Notification поставить `"async": true`, тогда Claude вообще не ждёт хук. Вариант `type:"http"` убирает запуск node совсем, но не работает для SessionStart. Ещё надо проверить, не показывает ли он уведомление об ошибке, когда бридж выключен (сейчас от этого защищает heartbeat).
- **RCON у бриджа один и последовательный.** Каждый эффект отнимает время у `setblock`. Нужна очередь эффектов с бюджетом на tick и дедупом по ключу.
- **Сущности.** Сейчас каждый дом даёт villager с AI, через 100 домов это уже заметная нагрузка на тики. Ставить NoAI (`NoAI:1b`) и ограничить число на квартал. Display-сущности дешёвые, но временные надо убивать и помечать тегом `alps_fx`.
- **Анимации** делать через `interpolation_duration`/`teleport_duration` один раз: дальше сервер ничего не считает, движение рисует клиент.

## Анти-идеи
- Эффект на **каждый** вызов инструмента: звук, частицы и чат на 3 вызова в секунду превращаются в шум. Вместо этого агрегировать и показывать только смену состояния.
- Сообщения в чат или `title` на рутинные события. Title оставить только для «ждёт тебя» и повышения статуса посёлка.
- Настоящая погода и молнии около жителей и домов: ведьмы, пожары, тёмный город.
- Отдельная сущность на каждый блок или каждый коммит (гирлянды из item_display, «кладбище» коммитов): мир медленно захламляется.
- Полный разбор транскрипта (тексты, файлы) и вывод путей и промптов на табличках. Это приватность, CPU и паразитный рост state.json.
- Paper-плагин ради мелочей: всё перечисленное делается ванильными командами и датапаком.
- Парсинг `last_assistant_message` ради шуток, а также ответы Claude через хук (stdout или `additionalContext`): это тратит токены и ломает главное обещание проекта.
